# User project template (Next.js App Router + TypeScript + Prisma)

Copied into a project's Gitea repo on bootstrap. The `aider-sandbox` image does
**not** bake this in — template updates do not require rebuilding the sandbox.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Prisma + PostgreSQL

## Local

```bash
yarn install
yarn dev
```

Set `DATABASE_URL` before running Prisma.
