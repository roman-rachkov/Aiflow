# hello-cli

## Goal and context

Цель приложения — простой CLI-инструмент на Node.js, который выводит в консоль строку "Hello, AIFlow!" и корректно завершает выполнение с кодом 0. Приложение не требует зависимостей, тестов или упаковки, предназначено для демонстрации минимальной функциональности.

## Users and roles

- **Пользователь CLI**: любой пользователь, запускающий скрипт в командной строке. Не предполагает различий ролей.

## Functional requirements

### Screen/Page "Запуск"

- **URL**: не применимо (CLI-инструмент)
- **Available to roles**: Пользователь CLI
- **Purpose**: Выполнить команду и вывести приветствие в консоль.
- **Interface elements**:
  - Input: команда запуска `node index.js`
- **States**:
  - **Обычное состояние**: выполнение скрипта завершается успешно с кодом 0
- **Logic**: При запуске `node index.js` в консоли отображается строка "Hello, AIFlow!" и процесс завершается.
- **Scope**: mvp-0

## Background processes

(Нет фоновых процессов, так как это простой однофайловый CLI-инструмент без асинхронной логики.)

### Job "Запуск скрипта"

- **Trigger**: запуск команды `node index.js`
- **Steps**:
  - Чтение файла `index.js`
  - Выполнение кода
  - Вывод строки в консоль
  - Завершение процесса с кодом 0
- **Failure handling**: Ошибки не предполагаются, так как скрипт простой.
- **Scope**: mvp-0

## Non-functional requirements

- **Platform**: CLI-инструмент (Node.js)
- **Stack**: Node.js (без фреймворков или дополнительных библиотек)
- **Design**: Минималистичный вывод в консоль
- **Deployment**: Прямой запуск через `node index.js`
- **Constraints**:
  - Один файл `index.js` без зависимостей
  - Нет тестов и упаковки
  - Вывод только одной строки: "Hello, AIFlow!"

## Assumptions and open questions

- Предполагается, что Node.js установлен в системе пользователя.
- Не требуется никаких параметров командной строки.
- Простой вывод строки без дополнительных действий.
