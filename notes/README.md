# Notes

Ideas captured for later. Written by the `notes` skill (usually via `/note`), one
file per note: `<YYYY-MM-DD>-<slug>.md`, each holding three blocks — the verbatim
note, an expansion into variants, and a critical analysis.

A note is not a commitment. Nothing here is planned or implemented until the user
decides it should be; `status: promoted` plus a roadmap link is what makes an idea
real work.
