## What the toolset is missing

**`PowerShell` — 16 attempts, zero availability.** Unchanged from the last run,
which means the previous fix (record it, don't work around it) has not taken
effect in behaviour. On a Windows host with Git Bash, PowerShell was expected
sixteen times. This is a requirement the environment has stated repeatedly.

**Bash displacing the dedicated tools:**

| Anti-pattern                       | Count | Against          |
| ---------------------------------- | ----- | ---------------- |
| Bash embedding `cat`/`head`/`tail` | 546   | 659 `Read` calls |
| Bash starting with `cd`            | 290   | 851 Bash (34%)   |
| Bash embedding `grep`/`rg`         | 256   | **136** `Grep`   |
| Bash embedding `find`              | 69    | 84 `Glob`        |

Nearly twice as much search goes through piped shell as through `Grep`, and it
got worse since the last run (242→256 against 125→136). The `cd` count also rose
(269→290) despite being flagged as pure tax: the shell working directory resets
between calls, and this session hit that directly — a `cd packages/db` followed
by a relative path produced `packages/db/packages/db/...`.

## Fixes

1. **Absolute paths, never `cd`.** 290 occurrences, and the failure mode is now
   demonstrated, not theoretical. `docs/17` § 3.3 already says this; it needs to
   be a hard rule with a cited failure, which § 3.5 below now provides.
2. **Cap identical retries at two, then change approach.** The classifier outage
   is intermittent, so one retry is justified; sixteen is not. After two, either
   proceed with a different tool or hand the command to the user.
3. **`PowerShell` → resolved, not re-flagged.** Two runs have reported 16
   attempts. Either the tool exists or Bash is the answer on this platform —
   record the latter in `docs/13-agent-tooling.md` § 1.1 and stop attempting it.
4. **Re-derive missing paths instead of retrying.** The 9× `Read` thrash and much
   of `path-not-found` share one cause: a path assumed rather than confirmed.
   `Glob` before `Read` when the location is uncertain.
5. **Leave the 115 environmental errors alone.** Recording them as not-ours is
   the fix; they are not a backlog.
