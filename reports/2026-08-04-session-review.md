## Where the flow went wrong

this is the whole point of the split:**

|                                 | Count   | Share of errors |

Half of every failure in this project is the permission classifier being

## What the toolset is missing

**`PowerShell` — 16 attempts, zero availability.** On a Windows host the agent
repeatedly expected a PowerShell tool and found none. That is a requirement the
environment has stated 16 times; it belongs in `docs/13-agent-tooling.md`, not in
a workaround.

**Bash is displacing the dedicated tools, heavily:**

| Anti-pattern                       | Count | Against                    |
| ---------------------------------- | ----- | -------------------------- |
| Bash embedding `cat`/`head`/`tail` | 514   | 625 `Read` calls           |
| Bash starting with `cd`            | 269   | 801 Bash calls total (34%) |
| Bash embedding `grep`/`rg`         | 242   | **125** `Grep` calls       |
| Bash embedding `find`              | 66    | 72 `Glob` calls            |

Bash accounts for 801 of 2197 calls (36%) and 115 of 226 errors — a 14.4% error
rate against `Grep`'s 2.4% and `Read`'s 3.7%. **Nearly twice as much search work
goes through piped shell as through `Grep`,** which is the single largest
correctable inefficiency in this data: the shell path returns unstructured text
and costs a separate permission decision every time.

## Fixes

1. **`PowerShell` → a registry row.** 16 attempts is a capability gap, not noise.
   Either add a tool or record that Bash is the answer on this platform.
2. **Absolute paths instead of `cd` prefixes.** The shell working directory resets
   between calls on Windows — 269 `cd` prefixes are pure tax, and several of the
   28 `path-not-found` errors follow directly from it.
3. **`Grep`/`Glob`/`Read` before `Bash`.** Codified as a rule in
   `docs/17-session-review.md` § 3.3 rather than left as an observation.
4. **Cap retries at three.** A signature that has failed three times in one
   session will not succeed on the sixteenth; escalate or change approach.
5. **Leave the classifier alone.** 112 environmental errors are not a backlog
   item. Recording them as "not ours" is the fix.
